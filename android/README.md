# Komment Cookie — Android sessionid grabber

Instagram'ga oddiy (o'z IP'ingizda) kirib, `sessionid`'ni avtomatik olib,
Telegram botga (`/add username sessionid`) yuboradigan kichik ilova.
Cheksiz telefonda ishlaydi. Login proxy orqali EMAS (Instagram bloklamaydi).

## APK'ni olish
1. GitHub → **Actions** → "Build Android APK" → oxirgi (yashil) run.
2. Pastda **Artifacts** → `komment-cookie-apk` → yuklab oling (zip ichida `app-debug.apk`).
3. Telefonga o'tkazing → o'rnating (Settings → "noma'lum manbalar"ga ruxsat bering).

## Ishlatish
1. Username yozing → **Ochish**.
2. Instagram'ga o'sha akkaunt bilan kiring (o'z internetingizda).
3. **Cookie olish** → "✅ sessionid olindi".
4. **Telegramga yubor** → Komment Qiroli botni tanlang → yuboring.
5. **Yangi akkaunt** → keyingisiga o'ting.
